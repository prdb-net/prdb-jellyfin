prdb

Identifies videos in movie libraries against prdb.net by file hash and file name, and fills in their metadata. The plugin only reads from prdb: it sends each file's name (without its folder), size and OSHash, and submits nothing.

Use a library of the content type Movies, ideally one of its own for these videos, and switch prdb on in it: Dashboard → Libraries → ⋮ → Manage library → tick prdb under Metadata downloaders (Movies) (and nothing else there) and under Image fetchers (Movies), each at the top. Libraries without prdb are never looked at. Setup guide

Connection

The API key of your own prdb account. Required: without it nothing is identified.
Leave as it is unless you were told otherwise.

Apply matches automatically

prdb says how far each match can be trusted. Choose which kinds the plugin applies on its own. Ambiguous matches and files only attributed to a site are never applied. To correct a match, enter the right prdb video id in the metadata editor; a set id is never replaced.
